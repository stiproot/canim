# Cloud Patterns Visualizations

Interactive 3D visualizations of distributed systems and cloud computing patterns using VPython.

## Installation

Requires Python 3.11.

```bash
pip install vpython
python <script_name>.py
```

## Visualizations

- **[Dapr Placement - Consistent Hashing](dapr-placement.md)** (`index.py`) - Consistent hashing with bounded loads and 3-phase commit
